# EpiTown — 像素小镇展示页

解压后上传本目录的全部内容即可，保留 `index.html`、`assets/`、`demo/` 的相对位置。不要只上传首页，也不要把 ZIP 本身当作网页上传。

## GitHub Pages

1. 将本目录内容放进用于展示的网站仓库根目录，保留 `.nojekyll`。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择对应分支和 `/(root)`，保存。
3. 等待 Pages 部署完成后，从该设置页的 Visit site 打开网站。

也可放在 `docs/` 后选择该目录为发布源。页面使用相对路径，兼容 GitHub 项目站点的仓库子路径。

GitHub 官方说明：<https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site>

## 内容与操作

- 首页：原始建筑素材构成街区、庭院与中央花园；点击建筑查看名称、功能和角色，说明显示在地图下方的独立区域；拖拽调节概念地图视角，支持缩放、复位和沉浸探索。选中建筑以地面标记突出，其他建筑保持原色。
- 城市 Demo：点击后按需载入；建筑/居民查看、定位与跟随、时间轴、暂停、变速、病程阶段和行动事件跳转。
- 研究沙盘：选择情境与信号区分度，单步、自动播放或跳到指定阶段；展示简化模型下的信念更新。
- 键盘：Tab 导航、方向键切换角色与实验标签；城市视角区支持方向键、+/- 与 Home；Esc 退出城市探索对话框。
- 页面动效可暂停，并尊重系统“减少动态效果”设置。

## Demo 来源与边界

来源：项目默认 `PHIA-DCMARL/versions/civic-v1/demo/`，由项目 README 与 `启动完整城市.ps1` 指向。工程种子为 91002；七天、50 位居民、27 栋建筑、1009 帧。没有改选表现更好的城市，也没有重新运行仿真。

演示保留原 `town.js` 字节及轨迹数据，只将图片引用调整为共享相对路径，并加入页面嵌入/暂停通信。它是已执行轨迹的回放，不是网页内实时训练或实时重新决策。

建筑使用项目 `assets/buildings/` 中的 27 张原始 PNG；字节保持不变，沿用原素材许可。首页只使用 SVG 视口调整素材显示范围，不重绘建筑。

研究沙盘与回放分开标注：沙盘数值来自预设说明模型，不属于真实实验数据；工程功能不等于已证明算法收益。

无需构建、安装依赖、配置密钥或服务器。完整解压后打开 `index.html`，点击“打开完整 Demo”会直接进入本地 `demo/town.html`，浏览器返回可回到首页。在 GitHub Pages 或本地 HTTP 服务上打开首页时，Demo 在首页内嵌载入。不要在 ZIP 预览中只打开一个 HTML，也不要移动或单独复制 HTML 文件。
