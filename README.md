# EpiTown — 透明玻璃与像素小镇展示页

解压后上传本目录的全部内容即可，保留 `index.html`、`assets/`、`demo/` 的相对位置。不要只上传首页，也不要把 ZIP 本身当作网页上传。

## GitHub Pages

1. 将本目录内容放进用于展示的网站仓库根目录，保留 `.nojekyll`。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择对应分支和 `/(root)`，保存。
3. 等待 Pages 部署完成后，从该设置页的 Visit site 打开网站。

也可放在 `docs/` 后选择该目录为发布源。页面使用相对路径，兼容 GitHub 项目站点的仓库子路径。

GitHub 官方说明：<https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site>

## 内容与操作

- 整体视觉：沿用浅绿色渐变与超大淡描边 `EpiTown.` 页尾，加入半透明玻璃导航、磨砂卡片、细高光边缘和圆润控件。地图保留在首屏标题右侧。玻璃模糊只作用于面板背后，建筑几何与纹理保持清晰。
- 公共服务 / 街区生活导览：首屏选择路线，点击站点或前后箭头切换建筑，镜头平滑定位。自动播放每 5.5 秒切换一站；手动操作、地图离屏、页面隐藏或暂停动效时停止自动播放。
- 快捷搜索：点击导航“探索”，或使用 Ctrl / Command + K、非输入状态下的 `/`。可搜索 38 栋建筑与 6 个章节；方向键选择，Enter 前往，Esc 关闭。
- 主题：右上角月亮按钮切换昼夜主题，偏好仅保存在本机。回放 Demo 保留其原始显示。
- 角色联动：点击四种角色标签或信息结构图节点，可查看对应建筑预览，再定位到地图。
- 方法闭环：三张方法卡片可切换详细说明，并跳转到沙盘的对应阶段。
- 信念对照：保存沙盘当前显示的三个概率，调整情境或信号区分度后比较变化；支持更新保存值和清除对照。数值属于概念演示，不是实验结果。
- 页面反馈：章节位置提示、阅读进度环、回顶、数字入场、卡片高光、按钮微动与点击涟漪。减少动态效果与页面暂停设置均受到尊重。

- 首页：38 款已审批的立体建筑，包含公共建筑、办公楼、居民公寓和居民小屋，围绕中央喷泉花园排列。拖动旋转、滚轮缩放、Shift / 右键平移，触屏双指缩放和平移。点击实际模型或下方目录选择建筑，可定位、单栋查看、对照原素材、下载原 GLB 模型。桌面端地图位于首屏标题右侧，窄屏上下排列。点选建筑后，说明在地图下方展开，不覆盖建筑。
- 分类和搜索：输入名称或编号筛选目录，同时淡化其他建筑；可切换俯视、全城复位、自动环绕和全屏。信息网络与干预脉冲属于解释性的可视化，不表示实时智能体数据或干预收益。
- 城市 Demo：点击后按需载入；建筑/居民查看、定位与跟随、时间轴、暂停、变速、病程阶段和行动事件跳转。
- 研究沙盘：选择情境与信号区分度，单步、自动播放或跳到指定阶段；展示简化模型下的信念更新。
- 键盘：Tab 导航、方向键切换角色与实验标签；地图获得焦点后支持方向键旋转、+/- 缩放、Home 复位、Esc 清除建筑选择。浏览器全屏可用 Esc 退出。
- 页面动效可暂停，并尊重系统“减少动态效果”设置。

## Demo 来源与边界

来源：项目默认 `PHIA-DCMARL/versions/civic-v1/demo/`，由项目 README 与 `启动完整城市.ps1` 指向。工程种子为 91002；七天、50 位居民、27 栋建筑、1009 帧。没有改选表现更好的城市，也没有重新运行仿真。

演示保留原 `town.js` 字节及轨迹数据，只将图片引用调整为共享相对路径，并加入页面嵌入/暂停通信。它是已执行轨迹的回放，不是网页内实时训练或实时重新决策。

回放继续使用 `assets/buildings/` 的 27 张原始 PNG，字节保持不变。首页独立展示完整素材库的 38 款立体重建模型，放在 `assets/town3d/models/`，与审批版 GLB 字节完全一致。建筑外观沿用原素材配色和部件纹理；原图不可见的背面为补全建模。38 栋展示地图与 27 栋历史回放是两个独立场景，未将新模型强行改写进原实验轨迹。

## 载入与验证

首页无外部 CDN 或运行时依赖。HTTP / GitHub Pages 读取 GLB；本地 file 模式读取相邻的 JS 模型数据，避免本地 fetch 限制。请同时保留两种文件，不要只复制首页。模型失败时提供重试；WebGL 不可用时显示完整地图预览，目录、原图对照和模型下载仍可使用。

地图布局、38 个模型与审批版的一致性、资源路径、JS 语法、19 项地图交互逻辑、12 项整页交互逻辑及原 Demo 的 50 项回归断言均经过程序检查。玻璃样式提供不支持背景模糊时的实色回退。当前环境的本地浏览器预览连接不可用，因此没有宣称完成真实浏览器的玻璃效果、WebGL 或实体触屏设备验收。

研究沙盘与回放分开标注：沙盘数值来自预设说明模型，不属于真实实验数据；工程功能不等于已证明算法收益。

无需构建、安装依赖、配置密钥或服务器。完整解压后打开 `index.html`，点击“打开完整 Demo”会直接进入本地 `demo/town.html`，浏览器返回可回到首页。在 GitHub Pages 或本地 HTTP 服务上打开首页时，Demo 在首页内嵌载入。不要在 ZIP 预览中只打开一个 HTML，也不要移动或单独复制 HTML 文件。
